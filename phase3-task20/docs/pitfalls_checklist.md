# Pitfalls Checklist (Study Guide §12) — Self-Audit

| Pitfall | Status in this build | Evidence |
|---|---|---|
| Pilot quality assumed from global metrics | Avoided | Metrics computed per-tenant, per-job (`experiments/metrics_offline.json`), not a global average |
| No agreed acceptance criteria | Partially avoided | Drafted in `docs/acceptance_criteria.md`; explicitly flagged as NOT YET SIGNED OFF by the real tenant |
| Shipping an offline win that never gets validated online | Avoided | `evaluate.py` reports offline vs. online-proxy gap explicitly and found they disagree — flagged in remediation, not hidden |
| Fairness audit done once, at the end, as a formality | Avoided | `fairness_audit.py` is a standalone, re-runnable script wired into `run_all.py`, not a one-off notebook cell |
| No model versioning | Avoided | `models/model_card.md` + `ranker_v1.joblib` filename versioning, generated by `model_registry.py` |

## Failure modes deliberately induced and confirmed (Stage E)
See `experiments/failure_test_report.json`:
1. Model artifact missing → falls back to baseline ranking (PASS)
2. Malformed candidate record (NaN skills) → degrades gracefully, does not crash (PASS after hardening — see `features.py` comment for the exact bug this test caught)
3. Empty candidate pool → returns empty list with reason, not an exception (PASS)
